# Connecteur CRM{#crm-connector}

L&#39;activité **Connecteur CRM** permet de paramétrer la synchronisation des données entre Adobe Campaign et un système CRM.

Avec cette activité, vous pouvez effectuer les actions suivantes :

* Import depuis le CRM
* Export vers le CRM
* Import d&#39;objets supprimés dans le CRM
* Suppression d&#39;objets dans le CRM

![Activité Connecteur CRM avec la liste Type ouverte affichant les options d&#39;import, d&#39;export et de suppression et le compte CRM Salesforce](assets/crm_task_select_op.png)

Sélectionnez le compte externe correspondant au CRM avec lequel vous souhaitez paramétrer une synchronisation puis choisissez l&#39;objet à synchroniser (comptes, opportunités, contacts, etc.).

![Activité Connecteur CRM avec Import depuis le CRM et ouverture de la liste d&#39;objets distants avec contact en surbrillance](assets/crm_task_select_obj.png)

Pour plus d’informations sur les connecteurs CRM dans Adobe Campaign, consultez [cette section](https://experienceleague.adobe.com/docs/campaign/campaign-v8/connect/ac-crm/crm.html?lang=fr){target="_blank"}.
