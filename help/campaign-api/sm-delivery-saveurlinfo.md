# SaveUrlInfo

Sauvegarde les URL de cette diffusion en tant que modèles d&#39;URL.

```text
SaveUrlInfo ( XML insUrlList, XML updUrlList )
```

## Paramètres

**insUrlList** Liste de nouvelles URL (non associées à un modèle d’URL)

**updUrlList** Liste des modèles d’URL à mettre à jour

## Valeur(s) renvoyée(s)

Aucune.

Oui
