# CreateFromModel

Création d&#39;une diffusion depuis un modèle (renseigné par son nom interne).

```text
XML delivery = CreateFromModel ( String scenarioName, XML content )
```

## Paramètres

**scenarioName** Nom interne du modèle de diffusion

Contenu XML **content** à ajouter au modèle

## Valeur(s) renvoyée(s)

**delivery** renvoie le document de diffusion créé

## Fonctionnalités

**Schéma :** [nms:delivery](s-nms-delivery.md)

**Statique :**

Oui
