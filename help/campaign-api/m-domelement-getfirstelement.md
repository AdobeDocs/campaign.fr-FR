# getFirstElement

Retourne le premier élément enfant en vérifiant les critères renseignés.

```text
getFirstElement (tagName [, attrName ] [, attrValue ])
```

## Paramètres

**tagName** Nom de l’élément recherché.

**attrName** Nom d’un attribut devant vérifier une valeur donnée.

**attrValue** Valeur de l&#39;attribut.

## Valeur renvoyée

Premier élément vérifiant le critère donné ou null.
