# CheckTableExists

Vérifie si une table existe dans la base de données

```text
Boolean exists = CheckTableExists ( String dataSource, String tableName )
```

## Paramètres

**source de données** Source de données

**tableName** Nom de la table

## Valeur(s) renvoyée(s)

Résultat **exists**

**Statique :**

Oui
