# insertBefore

Insérez un nœud avant une position spécifique.

```text
insertBefore (newChild, refChild)
```

## Paramètres

**newChild** Nœud à insérer.

**refChild** Nœud enfant qui doit suivre le nœud à insérer.

## Valeur renvoyée

Nœud inséré.
