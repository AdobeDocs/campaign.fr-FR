# GetDeliveryCustomizationAsModel

Copier les modèles de champs de personnalisation sélectionnés.

```text
XML parentOut = GetDeliveryCustomizationAsModel ( XML selection, XML parentIn )
```

## Paramètres

Élément **selection** contenant les identifiants des modèles sélectionnés

Élément **parentIn** contenant les personnalisations existantes

## Valeur(s) renvoyée(s)

**parentOut** renvoie l’élément avec les nouveaux modèles ajoutés

**Schéma :** [nms:operation](s-nms-operation.md)

**Statique :**

Oui
