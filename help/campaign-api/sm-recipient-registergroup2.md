# RegisterGroup2

Ajoute les destinataires sélectionnés à une liste

```text
RegisterGroup2 ( XML groupList, XML recipientList, XML clearGroup )
```

## Paramètres

**groupList** Listes

**liste des destinataires** Liste des destinataires

**clearGroup** Recréer la liste

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [nms:recipient](s-nms-recipient.md)

**Statique :**

Oui
