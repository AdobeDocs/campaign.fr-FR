# getParameter

Renvoie la valeur d’un paramètre de requête.

```text
getParameter (name)
```

## Paramètres

Nom du paramètre **name**.

## Valeur renvoyée

Valeur du paramètre demandé.

## Fonctionnalités

**Méthode de classe :** [HttpServletRequest](c-httpservletrequest.md)

**Disponible en :**

* JSSP
* WEBAPP
