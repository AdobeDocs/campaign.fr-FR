# DOMAttr (classe)

Nœud de type attribut.

## Propriétés

| Propriété | Description |
| --- | --- |
| [isId](p-domattr-isid.md) | true si l’attribut est d’un type ID. |
| [nom](p-domattr-name.md) | Nom de l’attribut. |
| [ownerElement](p-domattr-ownerelement.md) | L’élément avec cet attribut ou null. |
| [spécifié](p-domattr-specified.md) | true si la valeur est explicitement spécifiée (il ne s’agit pas d’une valeur implicite par défaut). |
| [valeur](p-domattr-value.md) | Valeur de texte d’attribut. |
