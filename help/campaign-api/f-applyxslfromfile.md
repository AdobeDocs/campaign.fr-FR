# applyXslFromFile

Transforme un document XML en utilisant une feuille de style XSL.

```text
applyXslFromFile (xslEntity, filename)
```

## Paramètres

**xslEntity** Nom de la feuille de style XSL stockée dans la base de données.

**nom_fichier** Nom du fichier XML à transformer.

## Valeur renvoyée

Le document XML sous la forme d’une chaîne de caractères après transformation.
