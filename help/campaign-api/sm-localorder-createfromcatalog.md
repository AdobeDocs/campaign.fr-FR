# CreateFromCatalog

Création d&#39;une commande depuis un kit.

```text
XML localOrder = CreateFromCatalog ( Number catalogId, Number orgUnitId )
```

## Paramètres

**catalogId** ID de package.

**orgUnitId** Identifiant de l’entité locale. (Facultatif)

## Valeur(s) renvoyée(s)

**localOrder** Renvoyer la commande créée.

## Fonctionnalités

**Schéma :** [nms:localOrder](s-nms-localorder.md)

**Statique :**

Oui
