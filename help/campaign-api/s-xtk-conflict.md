# conflit

> Avertissement : cette fonction est disponible pour un environnement On-Premise.

Stockage temporaire des entités en conflit.

## Méthodes

| Méthode | Description |
| --- | --- |
| [AcceptCus](sm-conflict-acceptcus.md) | Conserve la version actuelle. |
| [AccepterNouveau](sm-conflict-acceptnew.md) | Accepte la nouvelle version comme version actuelle. |
| [SetResolved](sm-conflict-setresolved.md) | Déclare une entité comme n&#39;ayant plus de conflits. |

## Méthodes génériques

| Méthode | Description |
| --- | --- |
| [créer](f-create.md) | Crée une nouvelle entité correspondant à un schéma donné. |
| [charger](f-load.md) | Charge et retourne une entité correspondant à un schéma et une clé donnés. |
| [enregistrer](m-entity-save.md) | Enregistre une entité dans la base de données. |
