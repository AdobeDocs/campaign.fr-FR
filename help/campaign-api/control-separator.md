# Séparateur

Afficher un séparateur avec un texte et une image.

![Contrôle du séparateur](assets/separator.70317a27.png)

## Propriétés

**direction - chaîne** horizontale par défaut.

**img - chaîne** image associée.

**libellé - chaîne** Texte à afficher.

## Remarques

Exemple:

```xml
      <static type="separator" label="Please enter your name here."/>

<static type="separator">Please enter your name here.</static>
```
