# GetInputValues

Recherche les valeurs possibles d&#39;une zone de saisie dans un formulaire.

```text
XML options = GetInputValues ( String schema, XML input )
```

## Paramètres

**schéma** Schéma d’édition de l’enquête.

Zone d’entrée **input**.

## Valeur(s) renvoyée(s)

**options** Valeurs possibles pour cette zone de saisie.

## Fonctionnalités

**Schéma :** [xtk:abstractForm](s-xtk-abstractform.md)

**Statique :**

Oui
