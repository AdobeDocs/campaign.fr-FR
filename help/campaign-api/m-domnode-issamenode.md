# isSameNode

Vérifie si la référence donnée représente le même nœud.

```text
isSameNode ()
```

## Paramètres

Aucune.

## Valeur renvoyée

true si les deux références représentent le même nœud, sinon false.

## Remarques

Cette méthode doit être utilisée pour comparer deux références. Les opérateurs JavaScript == et === ne peuvent pas être utilisés.
