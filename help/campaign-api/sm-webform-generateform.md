# GenerateForm

Génère le formulaire en mode Mail ou Web

```text
String result = GenerateForm ( String formName, Boolean mailMode )
```

## Paramètres

**formName** Nom du formulaire

**mailMode** Générer un formulaire de type Mail

## Valeur(s) renvoyée(s)

**résultat** Résultat de l’application du XSL sur le formulaire

## Fonctionnalités

**Schéma :** [nms:webForm](s-nms-webform.md)

**Statique :**

Oui
