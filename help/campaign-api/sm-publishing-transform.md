# Transform

Transformation de publication depuis un contenu

```text
[ String format, String result ] = Transform ( String publishingId, String modelName, XML content )
```

## Paramètres

**publishId** Identifiant du modèle de publication

**modelName** Nom du modèle de transformation

**contenu** Données de contenu à transformer

## Valeur(s) renvoyée(s)

**format** Format de sortie

**résultat** Résultat de la transformation
