# resetServiceMobileAppsCustomHook

Efface les paramètres supplémentaires des services web de toutes les mobileApp d&#39;un même service

```text
XML serviceOut = resetServiceMobileAppsCustomHook ( XML serviceContent )
```

## Paramètres

**serviceContent** Contenu du nœud de service actuel

## Valeur(s) renvoyée(s)

**serviceOut** Contenu du nœud de service après traitement

## Fonctionnalités

**Schéma :** [nms:mobileApp](s-nms-mobileapp.md)

**Statique :**

Oui
