# hasElement

Vérifie si l’élément a un élément enfant en vérifiant les critères donnés.

```text
hasElement (tagName [, attrName ] [, attrValue ])
```

## Paramètres

**tagName** Nom de l’élément recherché.

**attrName** Nom d’un attribut devant vérifier une valeur donnée.

**attrValue** Valeur de l&#39;attribut.

## Valeur renvoyée

true si l’élément a un enfant en vérifiant les données données, sinon false.
