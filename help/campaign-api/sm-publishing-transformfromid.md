# TransformFromId

Transformation de publication depuis un Id de contenu

```text
[ String format, String result ] = TransformFromId ( String publishingId, String modelName, String contentId )
```

## Paramètres

**publishId** Identifiant du modèle de publication

**modelName** Nom du modèle de transformation

Identifiant de contenu **contentId**

## Valeur(s) renvoyée(s)

**format** Format de sortie

**résultat** Résultat de la transformation
