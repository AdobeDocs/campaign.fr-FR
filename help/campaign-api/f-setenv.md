# setEnv

>[!WARNING]
>
>Cette fonction est disponible pour un environnement On-Premise.

>[!NOTE]
>
>Vous pouvez désactiver cette fonction en transmettant l’option **XtkSecurity\_Disable\_GetSetEnv** à **true**.

Définissez la valeur d’une variable d’environnement.

```text
setEnv (name, value)
```

## Paramètres

**name** Nom de la variable d’environnement.

**Valeur** Nouvelle valeur pour la variable d’environnement.

## Valeur renvoyée

Nouvelle valeur de la variable.
