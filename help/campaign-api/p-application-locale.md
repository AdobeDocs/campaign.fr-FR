# Paramètres régionaux

Renvoie une chaîne de caractères correspondant à l’instance locale.

```text
locale
```

## Remarques

Le local est un code qui définit les paramètres régionaux. Il est constitué d’un code de langue suivi d’un code de pays, séparés par le caractère « - ». Exemples de valeurs :

* en-US - Anglais, États-Unis
* en-GB - Anglais, Grande-Bretagne
* fr-FR - Français, France
* de-DE - Allemand, Allemagne
* es-ES - Espagnol, Espagne
