# Déployer

Déploiement des offres vers un environnement.

```text
Deploy ( XML offerFilter, Number offerEnv )
```

## Paramètres

**offerFilter** Condition de filtrage définissant les offres à copier

**offerEnv** Identifiant de l’environnement de destination

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [nms:offer](s-nms-offer.md)

**Statique :**

Oui
