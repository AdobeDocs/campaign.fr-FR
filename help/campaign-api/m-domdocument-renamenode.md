# renameNode

Modifie le nom d’un élément ou d’un attribut.

```text
renameNode (node, namespaceURI, qualifiedName)
```

## Paramètres

**nœud** nœud de type élément/attribut.

**namespaceURI** Nouvel URI d’espace de noms.

**qualifiedName** Nouveau nom qualifié.

## Valeur renvoyée

Nœud renommé. Il peut s’agir du nœud spécifié ou d’un nœud qui remplace l’ancien.
