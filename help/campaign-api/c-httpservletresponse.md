# HttpServletResponse (classe)

Représente la réponse d’un servlet renvoyée à un client.

Une seule instance de cette classe est accessible par la variable `response`.

## Méthodes

| Méthode | Description |
| --- | --- |
| [setContentType](m-httpservletresponse-setcontenttype.md) | Modifie le type de document de la réponse. |
| [sendRedirect](m-httpservletresponse-sendredirect.md) | Retourne une redirection temporaire vers une autre URL. |
| [ajouterCookie](m-httpservletresponse-addcookie.md) | Ajoute un cookie à la réponse. |
| [addHeader](m-httpservletresponse-addheader.md) | Ajoute un en-tête HTTP supplémentaire à la réponse. |
| [sendError](m-httpservletresponse-senderror.md) | Renvoie une réponse d’erreur à l’aide du code d’erreur transmis en tant que paramètre. |

## Fonctionnalités

**Disponible en :**

* JSSP
* WEBAPP
