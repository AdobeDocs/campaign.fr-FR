# SchemaKey (classe)

Représente la définition d’une clé.

## Propriétés

| Propriété | Description |
| --- | --- |
| [libellé](p-schemakey-label.md) | Renvoie la brève description de la clé. |
| [description](p-schemakey-description.md) | Renvoie la description de la clé. |
| [nom](p-schemakey-name.md) | Retourne l’identifiant de la clé. |
| [isInternal](p-schemakey-isinternal.md) | Renvoie true si la clé est la clé interne. |
| [allowEmptyPart](p-schemakey-allowemptypart.md) | Renvoie vrai si les champs de la clé peuvent être vides (au moins un des champs doit être renseigné). |
| [champs](p-schemakey-fields.md) | Renvoie une table qui contient le champ des champs ( [SchemaNode](c-schemanode.md) ) de la clé. |
