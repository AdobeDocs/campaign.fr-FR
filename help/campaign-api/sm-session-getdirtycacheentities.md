# GetDirtyCacheEntities

Renvoie les entités en cache pas à jour

```text
XML dirtyEntities = GetDirtyCacheEntities ( XML cacheEntities )
```

## Paramètres

**cacheEntities** Liste des entités mises en cache

## Valeur(s) renvoyée(s)

**dirtyEntities** Liste des entités sales
