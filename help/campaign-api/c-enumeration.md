# Enumération (Classe)

Représente la définition d’une énumération.

## Propriétés

| Propriété | Description |
| --- | --- |
| [baseType](p-enumeration-basetype.md) | Renvoie une chaîne de caractères qui fournit le type d’énumération. |
| [par défaut](p-enumeration-default.md) | Renvoie une chaîne de caractères qui fournit la valeur par défaut de l’énumération. |
| [description](p-enumeration-description.md) | Renvoie une chaîne de caractères qui fournit une description de l’énumération. |
| [hasImage](p-enumeration-hasimage.md) | Renvoie une valeur booléenne qui indique si l’énumération comporte une image. |
| [libellé](p-enumeration-label.md) | Renvoie une chaîne de caractères qui fournit le libellé de l’énumération. |
| [nom](p-enumeration-name.md) | Renvoie une chaîne de caractères qui fournit le nom de l’énumération. |
| [valeurs](p-enumeration-values.md) | Renvoie un objet pour lequel chaque propriété est un objet [EnumerationValue](c-enumerationvalue.md) indexé par sa valeur. |
