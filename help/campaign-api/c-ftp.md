# FTP (classe)

Un objet FTP vous permet d’effectuer un certain nombre d’opérations à l’aide du protocole FTP.

## Méthodes

| Méthode | Description |
| --- | --- |
| [FTP](m-ftp-ftp.md) | Crée un objet pour exécuter les commandes FTP. |
| [disposer](m-ftp-dispose.md) | Libère les ressources utilisées par l’objet . |
| [liste](m-ftp-list.md) | Retourne la liste des fichiers sur le serveur dans un répertoire spécifié. |
| [télécharger](m-ftp-download.md) | Télécharge un fichier du serveur vers un fichier local ou vers la mémoire. |
| [charger](m-ftp-upload.md) | Téléchargez un fichier depuis un fichier local vers un serveur FTP. |
| [setFile](m-ftp-setfile.md) | Définit le mode de transfert et le fichier de réception. |
