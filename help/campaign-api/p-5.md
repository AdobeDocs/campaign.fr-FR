# Utilisation des dates

Ce chapitre présente les fonctions de manipulation des dates dans les programmes JavaScript exécutés sur le serveur (workflow, JSSP, etc.).

## Dates et fuseaux horaires

Dans JavaScript, les dates sont stockées au format UTC. Cela signifie que vous n’avez qu’à vous soucier des fuseaux horaires pour la construction de la date ou la conversion en chaînes de texte pour l’affichage ou le stockage internes. Pour la conversion de date, il existe deux catégories de fonctions :

* les fonctions de la bibliothèque JavaScript (date.toString(), date.toLocaleString(), date.getHours(), ...),
* les fonctions de la plateforme Adobe Campaign ( [formatDate(date, format)](f-formatdate.md) ).

Par convention, les premiers utilisent le fuseau horaire de la machine tandis que les derniers utilisent un fuseau horaire dépendant du contexte : généralement celui de l&#39;opérateur courant, mais ce comportement peut être modifié pour les exports ou les workflows par exemple.

## Obtenir la date actuelle

Il existe deux manières d’obtenir la date actuelle dans JavaScript :

* new Date() crée un objet Date initialisé avec la date courante. La date correspond à l&#39;heure de la machine sur laquelle le script est exécuté.
* [getCurrentDate()](f-getcurrentdate.md) renvoie la date actuelle en fonction de l&#39;heure du serveur de base de données.

La fonction [getCurrentDate()](f-getcurrentdate.md) est préférable à la première solution, en particulier lorsque la date doit être comparée à d&#39;autres dates de la base de données ou être écrite dans la base de données. Cette méthode réduit le risque d’incohérences (jusqu’à plusieurs minutes) liées aux décalages horaires entre le serveur applicatif et le serveur de base de données

## Affichage des dates

La conversion d&#39;une date en chaîne de caractères à des fins d&#39;affichage utilise la fonction [formatDate](f-formatdate.md).

## Convertir une date à partir d&#39;un document XML

Les dates stockées dans un document XML provenant de la base de données Adobe Campaign sont sous forme de texte : elles peuvent être converties à l&#39;aide de la fonction [parseTimeStamp](f-parsetimestamp.md). Cela concerne généralement les documents XML renvoyés par la méthode [ExecuteQuery](sm-querydef-executequery.md). Exemple :

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "get", 
    select: {
      node: {expr: "@lastModified"}
    }, 
    where: {
      condition: {expr: "@id=123456"}
    }
  }}
)

var delivery = query.ExecuteQuery()
var lastModified = parseTimeStamp(delivery.$lastModified)
```

## Insérer une date dans un document XML

Qu&#39;il s&#39;agisse d&#39;écrire une date dans un attribut XML, d&#39;enregistrer un document (méthode [Write](sm-session-write.md)) ou d&#39;insérer une date littérale dans l&#39;expression d&#39;une requête, la date devra être convertie au format ISO8601. Il existe une méthode dans la bibliothèque de fonctions xtk:shared/nl.js pour convertir une date dans ce format : la méthode NL.XTK.formatDateTime(date). La bibliothèque peut être chargée à l’aide de la fonction loadLibrary :

```javascript
loadLibrary("xtk:shared/nl.js")
```

ou en utilisant la directive de page dans le cas d’une page JavaScript dynamique (JSSP) :

```xml
<%@ page import="xtk:shared/nl.js" %>
```

Avertissement : vous ne pouvez pas utiliser loadLibrary pour tous les scripts. Par exemple, vous ne pouvez pas modifier une bibliothèque de fonctions JavaScript dans un script de personnalisation d’e-mail. Exemple : cet exemple illustre la construction d’une requête à l’aide d’une date littérale.

```javascript
loadLibrary("xtk:shared/nl.js")
NL.require('/nl/core/shared/xtk.js')
...

var date = ...

var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "nms:delivery", operation: "select", 
    select: {
      node: {expr: "@id"}
    }, 
    where: {
      condition: {expr: "@lastModified > #" + NL.XTK.formatDateTime(date) + "#"}
    }
  }})

var result = query.ExecuteQuery()
```
