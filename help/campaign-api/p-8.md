# Protection des données : fonctions d&#39;échappement

Adobe Campaign propose un ensemble de fonctions qui assurent une protection contre les attaques les plus fréquentes : injections SQL, attaques XSS, etc.

Les fonctions d&#39;échappement doivent être utilisées sous la supervision des opérateurs et Adobe ne peut être tenu responsable de la mauvaise utilisation ou de l&#39;absence d&#39;utilisation de ces fonctions pendant les développements.

La règle générale est la suivante :

**Tous les paramètres doivent être placés dans une séquence d&#39;échappement. La fonction utilisée pour l&#39;échappement dépend du format de destination des données.**

## Échappement simplifié

Dans les JSSP, Adobe Campaign fournit la balise &#39;&lt;%=&#39; qui permet d&#39;échapper une variable utilisée dans une entité XML ou HTML générée. Cette méthode est plus pratique et équivaut à NL.XML.escape(). L’exemple suivant illustre l’utilisation de la balise pour échapper un paramètre :

```xml
<li>
<%= strRecipientList %>
</li>
```

## Échappement avancé :

Adobe Campaign fournit 4 fonctions qui vous permettent d’échapper un paramètre en fonction du format de destination. Pour accéder à ces fonctions d’échappement, nommez respectivement les fichiers suivants :

```javascript
NL.require('/nl/core/shared/xml.js')
NL.require('/nl/core/sql.js')
NL.require('/nl/core/shared/xtk.js')
NL.require('/nl/core/shared/js.js')
```

* NL.XML.escape(data) pour échapper une variable utilisée dans une entité XML ou HTML générée. Cette fonction est l&#39;équivalent de la syntaxe &#39;&lt;%=&#39;. Cette fonction est définie dans le package NL.XML.

  ```xml
  <tr>
  <td><%==NL.XML.escape(node.id)%><td>
  <td><%==NL.XML.escape(node.label)%><td>
  </tr>
  ```

* NL.SQL.escape(data) pour échapper un paramètre qui peut être utilisé dans une requête SQL. Cette fonction place automatiquement l’expression entre guillemets simples. Cette fonction est définie dans le package NL.SQL.

  ```javascript
            var strSql = "UPDATE NmsRecipient SET sEmail="+NL.SQL.escape(strEmail)+ " WHERE ...";
  ```

* NL.XTK.toXTKString(data) pour échapper un paramètre destiné à être utilisé dans une expression XTK. Cette fonction est définie dans le package NL.XTK.

  ```javascript
  var query = NLWS.xtkQueryDef.create(
    {queryDef: {schema: "nms:recipient", operation: "select", 
      select: {
        node: [
          {expr: "@firstName"}, 
          {expr: "@lastName"} 
        ]
      }, 
      where: {
        condition: {expr: "@email=" + NL.XTK.toXTKString(request.getParameter("query"))}
      }
    }})
  ```

* NL.JS.escape(data) pour échapper une variable utilisée dans javascript exécutée côté client. Cette fonction est définie dans le package NL.JS.

  ```xml
  <script type="text/javascript">
                var value = “Foo <%== NL.JS.escape(Node.@value) %>”; 
  </script>
  ```

Avertissement : Adobe Campaign ne garantit pas la pérennité de ces fonctions pour les versions ultérieures.
