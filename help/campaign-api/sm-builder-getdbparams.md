# GetDbParams

Récupère les paramètres actuels de la source de données.

```text
[ XML dbcnx, XML dbParameters ] = GetDbParams ()
```

## Paramètres

Aucune.

## Valeur(s) renvoyée(s)

**dbcnx** Définition de la source de données

**dbParameters** Mettez à jour les espaces de noms et les tablespaces.

**Statique :**

Oui
