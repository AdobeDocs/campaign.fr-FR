# logVerbose

Ajoute un message d’information dans le journal de l’instance de workflow. Ce message est uniquement visible en mode &#39;verbeux&#39;.

```text
logVerbose (message)
```

## Paramètres

**message** Message à ajouter au journal.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Message de diffusion
* Règle de typologie
* Import
* JSSP
* Méthode SOAP
* WebApp
* Workflow
