# DispatchImages

Indique au serveur applicatif d&#39;envoyer les images au serveur de mid-sourcing.

```text
DispatchImages ( String images, Number providerId, String providerName )
```

## Paramètres

**images** Liste des images à charger sur le serveur de mid-sourcing.

**providerId** Identifiant du routeur de diffusion.

**providerName** Nom du routeur de diffusion.

Aucune.
