# ResolvePackageReferences

Résout les dépendances présentes dans le package

```text
[ XML patchedPackage, Number warningNb ] = ResolvePackageReferences ( XML parameters )
```

## Paramètres

Élément XML **parameters** contenant le package à importer.

## Valeur(s) renvoyée(s)

Package **patchedPackage** traité.

**warningNb** Nombre d&#39;avertissements générés.
