# Exceptions JavaScript

Par défaut, lorsqu’une erreur se produit, le script en cours d’exécution est interrompu. La version 4.05 et les versions ultérieures ne vous permettent toutefois pas de capturer des erreurs et de les gérer afin de continuer le traitement du script.

Les exceptions levées par Adobe Campaign sont des codes d&#39;erreur (type `Number`).

## Exemple

Cet exemple tente de récupérer une page Web à partir d&#39;une adresse non valide et soulève une exception de la fonction [getUrl()](f-geturl.md).

```javascript
try
{
  var url = "xx:/invalid-url"
  getUrl(url)
}
catch(e)
{
  logInfo("Can't get page content: " + url )
  logInfo("Error number: " + e )
}

  
```
