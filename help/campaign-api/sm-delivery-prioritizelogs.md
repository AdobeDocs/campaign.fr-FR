# PriorizeLogs

Priorise les logs de diffusions d&#39;une liste de diffusions

```text
PrioritizeLogs ( Number id, XML deliveries, String logTable )
```

## Paramètres

Identifiant unique de la priorisation **id**

**diffusions** liste des diffusions à prendre en compte

**logTable** table contenant tous les messages du journal

## Valeur(s) renvoyée(s)

Aucune.
