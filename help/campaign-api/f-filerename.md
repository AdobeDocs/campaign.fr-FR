# fileRename

Modifie le nom d’un fichier.

Si le codage des caractères n’est pas spécifié, la valeur par défaut du serveur est utilisée.

```text
fileRename (oldname, newname)
```

## Paramètres

**oldname** Nom complet du fichier à renommer.

**newname** Nouveau nom du fichier.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Règle de typologie
* JSSP
* Méthode SOAP
* WebApp
* Workflow
