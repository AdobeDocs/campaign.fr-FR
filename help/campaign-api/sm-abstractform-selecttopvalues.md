# SelectTopValues

Récupère le top n des valeurs

```text
XML selectedValues = SelectTopValues ( String schema, String expr, Number classCount )
```

## Paramètres

**schéma** Schéma racine de l’analyse

Expression Source **expr**

**classCount** Nombre de classes à générer

## Valeur(s) renvoyée(s)

**selectedValues** Liste de valeurs

## Fonctionnalités

**Schéma :** [xtk:abstractForm](s-xtk-abstractform.md)

**Statique :**

Oui
