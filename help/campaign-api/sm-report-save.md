# Enregistrer

Enregistre un rapport déjà généré dans la base.

```text
XML result = Save ( XML data, String reportName )
```

## Paramètres

**données** Données utilisées par les rapports

**reportName** Nom interne du rapport

## Valeur(s) renvoyée(s)

**résultat** Identifiant unique et date d’enregistrement

## Fonctionnalités

**Schéma :** [xtk:report](s-xtk-report.md)

**Statique :**

Oui
