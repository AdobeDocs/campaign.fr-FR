# enregistrer

Enregistre l’archive.

```text
save ( [filename ] [, overwrite ])
```

## Paramètres

**nom de fichier** Nom de l’archive. Si le nom n’est pas spécifié ou est vide, l’archive est enregistrée sous son nom d’origine.

**remplacer** Si « false », l’archive n’est pas enregistrée si un fichier portant ce nom existe déjà et une exception est générée.

## Valeur renvoyée

Aucune.

**Méthode de classe :** [ZipFile](c-zipfile.md)
