# Cleansing des alias

Mise à jour de la base de données à l&#39;aide de toutes des énumérations soumises à l&#39;alias.

```text
AliasCleansing ( XML where, Date fromDate, Boolean refreshHit, Boolean resetHit )
```

## Paramètres

**où** filtre Énumérations.

**fromDate** Date de début des réponses au questionnaire.

**refreshHit** Mise à jour de l’accès.

**resetHit** Mise à jour des accès depuis le début.

## Valeur(s) renvoyée(s)

Aucune.
