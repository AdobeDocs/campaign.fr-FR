# getElementById

Retourne l&#39;élément avec l&#39;identifiant renseigné.

```text
getElementById (elementId)
```

## Paramètres

**elementId** Identifiant de l&#39;élément recherché. Chaîne de caractères avec respect de la casse.

## Valeur renvoyée

L’élément ou la valeur null si le document ne contient aucun élément avec un ID spécifique.
