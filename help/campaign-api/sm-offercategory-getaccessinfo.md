# GetAccessInfo

Restitue les propriétés héritées relatives au mode anonyme.

```text
[ Boolean anonymous, Boolean parentAnonymous ] = GetAccessInfo ( Number categoryId )
```

## Paramètres

**categoryId** ID de catégorie

## Valeur(s) renvoyée(s)

**anonyme** Indique si les offres de catégorie sont anonymes ou non

**parentAnonymous** Indique si les offres de la catégorie parente sont anonymes ou non

## Fonctionnalités

**Schéma :** [nms:offerCategory](s-nms-offercategory.md)

**Statique :**

Oui
