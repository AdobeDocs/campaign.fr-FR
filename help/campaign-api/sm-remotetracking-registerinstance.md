# RegisterInstance

Permet de valider une instance de tracking

```text
RegisterInstance ( String instanceName, String dbId, String lang )
```

## Paramètres

**instanceName** Nom de l’instance à approuver

Identifiant de base de données **dbId** pour le client effectuant une diffusion

**lang** Langue de l&#39;instance

## Valeur(s) renvoyée(s)

Aucune.
