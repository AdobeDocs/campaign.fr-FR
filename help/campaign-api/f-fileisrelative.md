# fileIsRelative

Indique si un nom de fichier est un nom relatif.

```text
fileIsRelative (fileName)
```

## Paramètres

**fileName** Nom du fichier.

## Valeur renvoyée

True si le nom de fichier est relatif.

## Fonctionnalités

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Règle de typologie
* JSSP
* Méthode SOAP
* WebApp
* Workflow
