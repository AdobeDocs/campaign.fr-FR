# allowEmptyPart

Renvoie vrai si les champs de la clé peuvent être vides (au moins un des champs doit être renseigné).

```text
allowEmptyPart
```

## Fonctionnalités

**Propriété de la classe :** [SchemaKey](c-schemakey.md)

**Lecture seule :**

Oui

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Règle de typologie
* JSSP
* Méthode SOAP
* WebApp
* Workflow
