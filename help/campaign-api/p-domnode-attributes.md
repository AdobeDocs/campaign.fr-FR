# attributs

Renvoie une table contenant la liste des attributs si le nœud est un élément, sinon null.

```text
attributes
```

## Remarques

Cette propriété crée une table pour chaque accès. Il est donc préférable de conserver la table dans une variable locale plutôt que d’accéder à la propriété plusieurs fois.
