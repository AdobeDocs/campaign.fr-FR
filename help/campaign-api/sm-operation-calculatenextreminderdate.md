```text
Date parentOut = CalculateNextReminderDate ( Date lastReminderDate, Date expectedDate, XML parameter )
```

## Paramètres

**lastReminderDate** Dernière date de rappel utilisée

**expectedDate** Date de validation

Configuration de **parameter**

Résultat **parentOut**
