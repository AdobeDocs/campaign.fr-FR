# LoadChildrenWithPath

Charge la liste des enfants d&#39;un nœud

```text
XML result = LoadChildrenWithPath ( String parentKey, String folderFilter, Boolean writeAccess, String fullName, String path, Boolean sort )
```

## Paramètres

**clé parente**

**folderFilter** Filtre sur les dossiers

**writeAccess** Le dossier renvoyé doit pouvoir être écrit

**fullName** Nom complet du nœud sélectionné

**chemin** Nom complet du nœud sélectionné

**trier** Trier par ordre alphabétique

## Valeur(s) renvoyée(s)

Document de résultat **result**

**Statique :**

Oui
