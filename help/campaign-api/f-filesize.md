# fileSize

Renvoie la taille d’un fichier en octets.

```text
fileSize (filename)
```

## Paramètres

**nom_fichier** Nom complet du fichier.

## Valeur renvoyée

Renvoie la taille du fichier ou -1 si une erreur s’est produite (par exemple, si le fichier est introuvable).
