# NotifyValidation

Notification de validation dans une opération.

```text
NotifyValidation ( Number deliveryId, Boolean target, Boolean content, Boolean budget, Boolean extraction, Boolean FCP, Boolean sandbox, Boolean edition, Boolean external )
```

## Paramètres

Identifiant de diffusion **deliveryId**

Validation du ciblage **target**

Approbation du contenu **content**

Approbation du budget **budget**

**extraction** Validation du fichier d&#39;extraction

**Approbation d&#39;épreuve FCP**

**sandbox** Validation de l’estimation de la cible

**édition** Modification de contenu

**externe** Validation externe du contenu

## Valeur(s) renvoyée(s)

Aucune.
