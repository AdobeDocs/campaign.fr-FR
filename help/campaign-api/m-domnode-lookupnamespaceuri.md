# lookupNamespaceURI

A recherché l’URI de l’espace de noms lié au préfixe donné.

```text
lookupNamespaceURI (prefix)
```

## Paramètres

Préfixe ****.

## Valeur renvoyée

URI de l’espace de noms ou chaîne vide si non trouvé.
