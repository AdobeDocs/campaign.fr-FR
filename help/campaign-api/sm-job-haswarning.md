# A un avertissement

Demande si des avertissements ou des erreurs ont été générés pour un traitement

```text

```

## Paramètres

Identifiant du traitement **id**

## Valeur(s) renvoyée(s)

**hasWarning** renvoie &#39;true&#39; s&#39;il y a eu au moins un message d&#39;avertissement ou d&#39;erreur
