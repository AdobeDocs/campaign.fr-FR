# AutoDetect

Lance une auto-détection et retourne les premières lignes du fichier

```text
XML result = AutoDetect ( String fileName, Number codepage )
```

## Paramètres

**fileName** Nom du fichier

**codepage** Encodage des caractères

## Valeur(s) renvoyée(s)

**result** renvoie les premières lignes du fichier

## Fonctionnalités

**Schéma :** [xtk:dataTransfer](s-xtk-datatransfer.md)

**Statique :**

Oui
