# isDefaultOnDuplicate

Renvoie une valeur booléenne. Si la valeur ajoutée est vraie, lors de la déduplication des enregistrements, la valeur par défaut (définie dans defaultValue) est automatiquement réappliquée lors de l&#39;enregistrement.

```text
isDefaultOnDuplicate
```
