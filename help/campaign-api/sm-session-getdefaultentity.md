# GetDefaultEntity

Retourne un document contenant une entité vide avec ses valeurs par défaut

```text
XML doc = GetDefaultEntity ( String schema )
```

## Paramètres

**schéma** Schéma de l’entité

## Valeur(s) renvoyée(s)

Résultat **doc**

**Schéma :** [xtk:session](s-xtk-session.md)

Oui
