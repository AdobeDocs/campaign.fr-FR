# setAttributeNS

Modifiez la valeur d’un attribut ou créez-en un.

```text
setAttributeNS (namespaceURI, qualifiedName, value)
```

## Paramètres

**namespaceURI** URI de l’espace de noms d’attribut.

**qualifiedName** Nom qualifié de l’attribut.

**value** Valeur de texte d’attribut.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Méthode de classe :** [DOMElement](c-domelement.md)

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Message de diffusion
* Règle de typologie
* Import
* JSSP
* Méthode SOAP
* WebApp
* Workflow
