# iOSGenerateCertificate

Encode en base64 le certificat iOS fourni

```text
String return = iOSGenerateCertificate ( String fileName, String uuid )
```

## Paramètres

**fileName** Nom du fichier

**uuid** UUID de l’application

## Valeur(s) renvoyée(s)

**return** Version base64 du certificat

## Fonctionnalités

**Schéma :** [nms:mobileApp](s-nms-mobileapp.md)

**Statique :**

Oui
