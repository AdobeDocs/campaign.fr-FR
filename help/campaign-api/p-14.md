# Échantillons

## Méthodes statiques

Pour accéder aux méthodes SOAP, appelez une méthode sur l’objet représentant le schéma. Les schémas sont des objets globaux &#39;NLWS&#39;. L’exemple suivant appelle la méthode statique [PostEvent](sm-workflow-postevent.md) du schéma [xtk:workflow](s-xtk-workflow.md).

```javascript
      NLWS.xtkWorkflow.PostEvent("WKF1", "signal", "", {variables: {foo: 'bar'}}, false)
    
```

## Méthodes non statiques

Pour utiliser les méthodes SOAP non statiques, vous devez d’abord récupérer une entité à l’aide des méthodes [load](f-load.md) ou [create](f-create.md) sur les schémas correspondants. L&#39;exemple suivant appelle la méthode [ExecuteQuery](sm-querydef-executequery.md) du schéma [xtk:queryDef](s-xtk-querydef.md).

```javascript
var query = NLWS.xtkQueryDef.create(
  {queryDef: {schema: "xtk:workflow", operation: "select", 
    select: {
      node: {expr: "@internalName"}
    }, 
    where: {
      condition: {expr: "[folder/@name]='wfExamples'"}
    }, 
    orderBy: {
      node: {expr: "@internalName", sortDesc: "false"}
    }
  }})

var res = query.ExecuteQuery()

for each (var w in res.getElements("workflow"))
  logInfo(w.$internalName)
    
```

## Limites

Certains appels non statiques ne peuvent pas être utilisés car l&#39;objet en cours de chargement (\*\*) manque de données. C&#39;est le cas, par exemple, pour certains appels sur [nms:delivery](s-nms-delivery.md).
