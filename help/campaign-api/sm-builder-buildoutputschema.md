# BuildOutputSchema

Génère un schéma depuis un schéma source.

```text
XML schema = BuildOutputSchema ( XML source, Boolean saveEntity )
```

## Paramètres

Schéma Source **source**

**saveEntity** Enregistrer le schéma après la génération

## Valeur(s) renvoyée(s)

**schéma** Schéma généré
