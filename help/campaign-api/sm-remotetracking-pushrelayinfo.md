# PushRelayInfo

Permet de charger sur les serveurs de tracking distants les informations concernant une diffusion.

```text
PushRelayInfo ( String instance, String dbId, XML document )
```

## Paramètres

**nom de l’instance**

Identifiant de la base de données du client **dbId**

**document** contenant des données

## Valeur(s) renvoyée(s)

Aucune.

Oui
