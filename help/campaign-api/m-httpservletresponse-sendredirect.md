# sendRedirect

Retourne une redirection temporaire vers une autre URL.

```text
sendRedirect (location)
```

## Paramètres

URL de redirection **location**.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Méthode de classe :** [HttpServletResponse](c-httpservletresponse.md)

**Disponible en :**

* JSSP
* WEBAPP
