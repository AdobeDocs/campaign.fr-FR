# Cookie (Classe)

Représente un cookie échangé par le servlet et le navigateur web.

## Propriétés

| Propriété | Description |
| --- | --- |
| [nom](p-cookie-name.md) | Nom du cookie. |
| [commentaire](p-cookie-comment.md) | Commentaire décrivant la fonction du cookie, nul si non défini. |
| [domaine](p-cookie-domain.md) | Nom de domaine du cookie. |
| [maxAge](p-cookie-maxage.md) | Durée de vie du cookie en secondes. |
| [chemin](p-cookie-path.md) | Chemin d’accès en fonction duquel le navigateur web transfère le cookie. |
| [sécurisé](p-cookie-secure.md) | true si le cookie ne peut être transféré que via un protocole sécurisé. |
| [valeur](p-cookie-value.md) | Valeur du cookie. |
| [version](p-cookie-version.md) | Version du protocole avec lequel le cookie est compatible. |

## Fonctionnalités

**Disponible en :**

* JSSP
* WEBAPP
