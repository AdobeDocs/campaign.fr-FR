# se débarrasser

Libère les ressources utilisées par l’objet .

```text
dispose ()
```

## Paramètres

Aucune.

## Valeur renvoyée

Aucune.

## Remarques

Cette méthode est utile pour libérer les ressources utilisées par l’objet sans attendre que l’objet soit finalisé par le garbage collector ou à la fin du script.
