# nodeType

Type de nœud.

```text
nodeType
```

## Remarques

Les valeurs possibles sont les suivantes :

* 1 Elément
* 2 Attribut
* 3 Texte
* 4 CDATA
* 5 Référence d’entité
* 6 Entité
* 7 Instruction de traitement
* 8 Commentaire
* 9 Document
* 10 Type de document
* 11 Fragment de document
* Notation 12
