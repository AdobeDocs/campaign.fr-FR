# mkdir

Crée un répertoire avec le chemin d&#39;accès de l&#39;objet [File](c-file.md) actif.

```text
mkdir ()
```

## Paramètres

Aucune.

## Valeur renvoyée

Aucune.

## Remarques

Crée également des répertoires intermédiaires si nécessaire. Une exception est générée en cas d’erreur.
