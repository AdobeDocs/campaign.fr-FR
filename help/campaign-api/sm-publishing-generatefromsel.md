# GenerateFromSel

Génère et publie une liste de contenu depuis une sélection

```text
GenerateFromSel ( XML contentList )
```

## Paramètres

**contentList** Sélection du ou des contenus à générer

## Valeur(s) renvoyée(s)

Aucune.
