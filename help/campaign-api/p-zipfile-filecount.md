# fileCount

Renvoie le nombre de fichiers dans l’archive.

```text
fileCount
```

## Remarques

L&#39;archive doit avoir été ouverte avec la méthode ⌐[open()](m-zipfile-open.md) avant de pouvoir utiliser cette méthode. Sinon, une exception est générée.
