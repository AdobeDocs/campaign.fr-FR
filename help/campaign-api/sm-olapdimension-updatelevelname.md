# UpdateLevelName

Met à jour le nom interne d&#39;un niveau en fonction de son expression.

```text
XML result = UpdateLevelName ( XML level, XML dimension )
```

## Paramètres

**level** niveau à modifier

**dimension** Dimension parente du niveau

## Valeur(s) renvoyée(s)

**niveau de résultat** modifié
