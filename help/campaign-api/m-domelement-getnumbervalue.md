# getNumberValue

Renvoie la valeur du nœud numérique référencé par le XPath donné.

```text
getNumberValue (xpath)
```

## Paramètres

**chemin**.

## Valeur renvoyée

Une valeur numérique correspond au nœud référencé.

## Remarques

La syntaxe du XPath accepte uniquement un sous-ensemble de langues XPath. Une exception est générée si le chemin est mal formé ou si la valeur n’est pas un nombre valide.
