# BuildTableList

Récupère une liste de noms de tables.

```text
XML tableList = BuildTableList ( String dataSource, String tablePattern )
```

## Paramètres

**dataSource** ID de la source de données

**tablePattern** : masque le nom de la table

## Valeur(s) renvoyée(s)

**tableList** listes de tables existantes

## Fonctionnalités

**Schéma :** [xtk:sqlSchema](s-xtk-sqlschema.md)

**Statique :**

Oui
