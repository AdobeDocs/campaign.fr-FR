# CreateInstanceFromModel

Instancie une instance d&#39;un objet depuis un modèle

```text
Number output = CreateInstanceFromModel ( String schema, Number modelId, XML diff )
```

## Paramètres

**schéma** Schéma de l’instance

**modelId** ID du modèle

**diff** correctif XML à appliquer au modèle

## Valeur(s) renvoyée(s)

**identifiant de sortie** de l’instance créée
