# HtmlToText

Convertit du contenu Html en texte simple

```text
String textContent = HtmlToText ( String htmlContent )
```

## Paramètres

**htmlContent** du contenu HTML à convertir

## Valeur(s) renvoyée(s)

**textContent** renvoie du texte converti
