# Aide

Affichez un texte et une image.

![Contrôle de l&#39;aide](assets/help.67cf3e33.png)

## Propriétés

**img - chaîne** image associée.

**libellé - chaîne** Texte à afficher.

## Remarques

Exemple:

```xml
      <static type="help" label="Please enter your name here."/>

<static type="help">Please enter your name here.</static>
```
