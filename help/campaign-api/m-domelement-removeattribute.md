# removeAttribute

Supprimez un attribut.

```text
removeAttribute (name)
```

## Paramètres

**name** Nom de l’attribut.

## Valeur renvoyée

Aucune.

## Remarques

La méthode n’a aucun effet si l’élément ne comporte aucun attribut de ce nom.
