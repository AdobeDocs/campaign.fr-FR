# PostUpload

Finalise l&#39;enregistrement de la ressource suite au chargement sur le serveur en fonction du type de stockage défini.

```text
fileRes.PostUpload ( XML params )
```

## Paramètres

**params** Pour le stockage de type &#39;workspace&#39; : @formerFileName contient le nom précédent dans l&#39;espace de travail. Si vous souhaitez enregistrer l&#39;entité immédiatement : @immediateSave doit être défini sur &#39;true&#39;

Aucune.
