# S&#39;abonner

Abonne un compte opérateur à un forum de discussion.

```text
Subscribe ( Number operatorId, String schema, Number entityId )
```

## Paramètres

**operatorId** ID d’opérateur

**schéma** Schéma de l&#39;entité associée au forum

**entityId** ID de l’entité liée au forum

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [nms:newsgroup](s-nms-newsgroup.md)

**Statique :**

Oui
