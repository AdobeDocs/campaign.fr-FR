# CreateWorkflowFromModelId

Créer un workflow dans une campagne à partir d&#39;un modèle de workflow.

```text
Number workflowId = CreateWorkflowFromModelId ( Number modelId, XML operationPlanning )
```

## Paramètres

Identifiant du modèle de workflow **modelId**

Planning de campagne **operationPlanning**

## Valeur(s) renvoyée(s)

**workflowId** Identifiant de l’instance créée
