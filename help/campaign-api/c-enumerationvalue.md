# EnumerationValue (classe)

Représente la définition d’une valeur d’énumération.

## Propriétés

| Propriété | Description |
| --- | --- |
| [libellé](p-enumerationvalue-label.md) | Renvoie une chaîne de caractères qui fournit la brève description de la valeur d’énumération actuelle. |
| [description](p-enumerationvalue-description.md) | Renvoie une chaîne de caractères qui fournit la description de la valeur d’énumération actuelle. |
| [valeur](p-enumerationvalue-value.md) | Renvoie une chaîne de caractères qui fournit la valeur de la valeur d’énumération actuelle. |
| [nom](p-enumerationvalue-name.md) | Renvoie une chaîne de caractères qui fournit le nom de la valeur d’énumération active. |
| [Image](p-enumerationvalue-image.md) | Renvoie une chaîne de caractères qui fournit le nom de l’image de la valeur d’énumération actuelle. |
| [enabledIf](p-enumerationvalue-enabledif.md) | Renvoie une chaîne de caractères qui fournit les conditions de validité de la valeur d’énumération actuelle. |
