# setFile

> Avertissement :
>
> L’accès via les API de fichiers est limité aux dossiers **var**, **sftp** et temporaires d’Adobe Campaign.

Définit le mode de transfert et le fichier de réception.

```text
setFile (filename)
```

## Paramètres

**nom** Nom du fichier local.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Méthode de classe :** [FTP](c-ftp.md)

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Règle de typologie
* JSSP
* Méthode SOAP
* WebApp
* Workflow
