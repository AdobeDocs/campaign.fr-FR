# transitionByType

Renvoie la transition correspondant au type donné.

```text
transitionByType (type)
```

## Paramètres

Type **type** de la transition.

## Valeur renvoyée

Première transition à avoir le type passé en paramètre, sinon null si l&#39;activité n&#39;a pas de transition de ce type.
