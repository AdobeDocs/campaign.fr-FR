# CheckAccess

Vérifie si le compte opérateur actuel a accès à la tâche.

```text
Boolean result = CheckAccess ( XML taskEntity )
```

## Paramètres

**taskEntity** entité de tâche

## Valeur(s) renvoyée(s)

**result** Valeur de retour de la méthode (oui/non)

## Fonctionnalités

**Schéma :** [nms:task](s-nms-task.md)

**Statique :**

Oui
