# SysEnum

Ce contrôle permet de choisir une valeur dans une énumération système.

![Contrôle SysEnum](assets/sysenum.1eccf324.png)

## Propriétés

**backColor - string** Couleur d&#39;arrière-plan (ombre btn, blanc).

**border - string** Modifie le style du contour de contrôle (uni, double, incrustation, départ, aucun).

**defaultIfInvalid - chaîne** Valeur à utiliser si la valeur n’est pas valide.

**enum - string** Énumération à utiliser.

**font-size - integer** Modifie la taille de la police.

**libellé - chaîne** libellé associé.

**noInvalidErr - boolean** N’affiche pas d’erreur si la valeur n’est pas valide.

**nolabel - boolean** Masque le libellé associé.

**readOnly - boolean** Force le contrôle en lecture seule.

**obligatoire - booléen** Le champ est obligatoire.

**serialize - boolean** Enregistre la dernière valeur sélectionnée.

**useDesc - boolean** Affiche la description plutôt que le libellé.

**xpathEnum - xpath** Utilise la valeur référencée par ce XPath plutôt que la propriété d’énumération pour l’énumération.
