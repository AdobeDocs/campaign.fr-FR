# useNChar

Renvoie true si Adobe Campaign utilise des champs de type NCHAR, NVARCHAR, NCLOB, NTEXT.

```text
useNChar
```

## Fonctionnalités

**Propriété de la classe :** [DBEngine](c-dbengine.md)

**Lecture seule :**

Oui

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Règle de typologie
* JSSP
* Méthode SOAP
* WebApp
* Workflow
