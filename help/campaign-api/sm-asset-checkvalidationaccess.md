# CheckValidationAccess

Vérifie si le compte opérateur actuel a accès à la validation de la ressource.

```text
Boolean result = CheckValidationAccess ( XML validation, Number ownerId )
```

## Paramètres

Paramètres de validation de **validation**

**ownerId** Identifiant de la personne désignée (propriétaire)

## Valeur(s) renvoyée(s)

**result** Valeur de retour de la méthode (oui/non)

## Fonctionnalités

**Schéma :** [nms:asset](s-nms-asset.md)

**Statique :**

Oui
