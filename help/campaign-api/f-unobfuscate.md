# désobscurcir

Dissipe l’entier précédemment obscurci grâce à [obfuscate](f-obfuscate.md).

```text
unobfuscate (value [, version ])
```

## Paramètres

**value** Entier à obscurcir.

**version** Version d’annulation de l’obscurcissement à appliquer. 0 par défaut.

## Valeur renvoyée

Entier précédemment obscurci par [obfuscate](f-obfuscate.md).

## Fonctionnalités

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Message de diffusion
* Règle de typologie
* Import
* JSSP
* Méthode SOAP
* WebApp
* Workflow
