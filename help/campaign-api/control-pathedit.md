# PathEdit

Contrôle pour sélectionner un champ.

## Propriétés

**backColor - string** Couleur d&#39;arrière-plan (ombre btn, blanc).

**border - string** Modifie le style du contour de contrôle (uni, double, incrustation, départ, aucun).

**font-size - integer** Modifie la taille de la police.

**hideCalculated - boolean** masque les champs calculés.

**hideMappedAsXml - booléen** : masque les champs XML.

**libellé - chaîne** libellé associé.

**nolabel - boolean** Masque le libellé associé.

**noTransaction - boolean** Désactive le mode transactionnel.

**readOnly - boolean** Force le contrôle en lecture seule.

**obligatoire - booléen** Le champ est obligatoire.

**useLink11Path - booléen** affiche les liens 1:1.

**useTablePath - boolean** Affiche les tableaux.

**useUnboundPath - booléen** Affiche les collections.

**xpath - string** Champ à modifier.

**xpathBaseType - xpath** Chemin d&#39;accès pour le stockage du type du champ sélectionné.

**xpathDataPolicy - xpath** Chemin d&#39;accès pour le stockage de la propriété dataPolicy du champ sélectionné.

**xpathEnum - xpath** Chemin d&#39;accès pour le stockage de l&#39;énumération système du champ sélectionné.

**xpathLabel - string** Chemin d&#39;accès pour le stockage du libellé du champ sélectionné.

**xpathSchema - chaîne** Chemin du schéma.

**xpathSchemaMd5 - xpath** Chemin de stockage du MD5 du schéma.

**xpathStartPath - chaîne** Chemin d’accès de startPath (utilisé uniquement si xpathSchema est défini).

**xpathUnbound - xpath** Chemin d&#39;accès pour le stockage de la propriété unbound du champ sélectionné.

**xpathUserEnum - xpath** Chemin d&#39;accès pour le stockage de l&#39;énumération libre du champ sélectionné.

**xpathType - xpath** Chemin d&#39;accès pour le stockage du contrôle par défaut du champ sélectionné.

**zoom - booléen** Affiche le bouton de modification.
