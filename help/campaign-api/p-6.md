# Utilisation de XML

De nombreuses API JavaScript prennent des objets de type XML comme paramètres ou les renvoient. Pour ce faire, les versions précédentes d’Adobe Campaign utilisaient l’extension JavaScript E4X, ce qui permettait de manipuler directement les éléments XML dans la langue. Cependant, cette technologie est peu à peu abandonnée.

Pour remplacer cette technologie, de nouveaux objets ont été ajoutés pour manipuler les documents XML. Ils reprennent un sous-ensemble de l’interface du modèle d’objet de document (DOM) avec certaines extensions. Un objet de notation est également disponible pour créer facilement des documents XML. Il s’agit d’une version simplifiée de la convention JSON BadgetFish.

## Interface DOM

Un objet [DOMDocument](c-domdocument.md) est un document XML. Il peut être composé d’une chaîne de caractères, d’un objet JSON ou directement à partir d’un fichier. Voici un exemple de création d’un document DOM :

```javascript
var doc  = new DOMDocument("recipient")
var root = doc.root
root.setAttribute("id", 12345)
var firstName = doc.createElement("firstName")
firstName.textContent = "John"
root.appendChild(firstName)

logInfo(doc.toXMLString(true))
```

Cette interface fait partie de la spécification W3C avec diverses différences notables :

* Les fonctions getElements\* ainsi que les propriétés childNodes et attributes renvoient une table JavaScript plutôt qu&#39;un objet NodeList, ce qui permet d&#39;utiliser les propres fonctions des tables : forEach, map, ...
* Certaines propriétés renvoient une chaîne vide plutôt qu’une valeur nulle lorsque la valeur n’a pas été spécifiée.

En outre, certaines fonctions d&#39;utilitaire et certaines extensions non standard ont été ajoutées. Par exemple, pour lire ou modifier un attribut, il suffit d’écrire :

```javascript
aRecipient.$firstName
aRecipient.$firstName = "John"
```

au lieu de :

```javascript
aRecipient.getAttribute("firstName")
aRecipient.setAttribute("firstName", "John")
```

L&#39;attribution d&#39;un attribut avec la propriété $name peut prendre une chaîne, une valeur booléenne, une date ou un nombre, la valeur sera automatiquement convertie en chaîne de caractères :

```javascript
aRecipient.$firstName = "John"
aRecipient.$lastModified = new Date()
aRecipient.$age = 35
aRecipient.$blocklist = false
```

## JXON

JXON est une convention de notation pour les objets JavaScript permettant de créer facilement des documents XML. Cette notation ne vous permet pas de créer tous les documents XML possibles. Par exemple, elle ne vous permet pas de spécifier un élément portant le même nom qu’un attribut et les espaces de noms ne sont pas gérés. Il est adapté aux documents Adobe Campaign. Pour des besoins plus complexes, vous pouvez toujours utiliser les fonctions DOM traditionnelles (analyse ou création élément par élément). L’objet XML est représenté par un objet JavaScript dont les propriétés correspondent aux éléments et attributs. Le type de valeur détermine s’il s’agit d’un élément ou d’un attribut.

* Chaîne Attribut dont la valeur est la chaîne de caractères
* Booléen Attribut dont la valeur est &#39;true&#39; ou &#39;false&#39;
* Nombre Attribut dont la valeur est une représentation numérique décimale
* Date Attribut dont la valeur est la représentation ISO-8601 de la date et de l’heure
* Objet Un élément
* Tableau Liste d’éléments

Une propriété spéciale sous le nom de $ est utilisée pour le contenu texte d’un élément Exemples :

> **JXON:**
>
> ```javascript
> { alice: { $: "bob" } }
> ```
>
> **XML :**
>
> ```xml
> <alice>bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: { $: "charlie" }, 
>     david: { $: "edgar" }
> }}
> ```
>
> **XML :**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <david>edgar</david>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     bob: [
>         { $: "charlie" }, 
>         { $: "david" } ]
> }}
> ```
>
> **XML :**
>
> ```xml
> <alice>
>     <bob>charlie</bob>
>     <bob>david</bob>
> </alice>
> ```
>
> **JXON:**
>
> ```javascript
> { alice: { 
>     charlie: "david",
>     $: "bob"
> }}
> ```
>
> **XML :**
>
> ```xml
>                             <alice charlie="david">bob</alice>
> ```
>
> **JXON:**
>
> ```javascript
> { recipient: {
>     firstName: "John",
>     id: 1234,
>     "creation-date": getCurrentDate(),
>     blocklist: false
> }}
> ```
>
> **XML :**
>
> ```xml
> <recipient
>     firstName="John"
>     id="1234"
>     creation-date="2013-04-19 10:58:22Z"
>     blocklist="false"/>
> ```

Lorsque les propriétés contiennent des caractères spéciaux qui ne sont pas des identifiants JavaScript valides, ils doivent être mis entre guillemets.

```javascript
{ recipient: { "recipient-id" : 1234 }}
      
```

Les objets JSON peuvent être utilisés dans des arguments partout où une fonction anticipe un document ou un élément XML. Par exemple :

```javascript
var doc = DOMDocument.fromJXON({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
var query = NLWS.xtkQueryDef.create(doc)
```

équivaut à :

```javascript
var query = NLWS.xtkQueryDef.create({queryDef: 
    {schema: "xtk:workflow", operation: "select",
      select: { node: {expr: "@internalName"} } 
    }
  })
```

Il est important de noter que la manipulation des documents XML est effectuée par des objets DOM. Les objets JSON sont des utilitaires utilisés uniquement pour l’initialisation. Il est plus utile de créer un document XML à partir d’une structure JavaScript littérale, en particulier lorsque le document contient des parties variables.
