# getValue

Renvoie la valeur du nœud référencé par le XPath donné.

```text
getValue (xpath)
```

## Paramètres

**chemin**.

## Valeur renvoyée

Valeur textuelle du nœud référencé.

## Remarques

La syntaxe du XPath accepte uniquement un sous-ensemble de langues XPath. Une exception est générée si le chemin est mal formé.
