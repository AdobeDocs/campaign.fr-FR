# WebPostUpload

Finalise l’enregistrement de la ressource suite au chargement (à partir d’une page web) sur le serveur en fonction du type de stockage défini. Récupère la page de codes et le type de contenu.

```text
fileRes.WebPostUpload ( XML params )
```

## Paramètres

**params** Pour le stockage de type &#39;workspace&#39; : @formerFileName contient le nom précédent dans l&#39;espace de travail. Si vous souhaitez enregistrer l&#39;entité immédiatement : @immediateSave doit être défini sur &#39;true&#39;

## Valeur(s) renvoyée(s)

Aucune.
