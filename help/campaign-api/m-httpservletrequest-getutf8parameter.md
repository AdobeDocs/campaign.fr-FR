# getUTF8Parameter

Renvoie la valeur (codée en UTF-8) d’un paramètre de la requête.

```text
getUTF8Parameter (name)
```

## Paramètres

Nom du paramètre **name**.

## Valeur renvoyée

Valeur du paramètre demandé.

## Fonctionnalités

**Méthode de classe :** [HttpServletRequest](c-httpservletrequest.md)

**Disponible en :**

* JSSP
* WEBAPP
