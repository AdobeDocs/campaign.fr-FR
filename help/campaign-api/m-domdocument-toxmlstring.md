# toXMLString

Convertit le document XML en une chaîne de caractères.

```text
toXMLString (format)
```

## Paramètres

**format** Valeur booléenne utilisée pour formater le document XML.

## Valeur renvoyée

Aucune.

## Remarques

Cette méthode ajoute le prologue, contrairement à la méthode portant le même nom sur les éléments .
