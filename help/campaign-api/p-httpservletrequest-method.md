# method

Renvoie une chaîne de caractères contenant la méthode HTTP utilisée pour appeler cette requête (GET, HEAD, POST, etc.).

```text
method
```

## Fonctionnalités

**Propriété de la classe :** [HttpServletRequest](c-httpservletrequest.md)

**Lecture seule :**

Oui

**Disponible en :**

* JSSP
* WEBAPP
