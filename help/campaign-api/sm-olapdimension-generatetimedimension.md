# GenerateTimeDimension

Générer une dimension temporelle.

```text
XML result = GenerateTimeDimension ( XML dimension, XML field, XML dates )
```

## Paramètres

**dimension** Dimension à entrer

**champ** Champ ou expression utilisé(e)

**dates** Description de la date

## Valeur(s) renvoyée(s)

**résultat** Dimension saisie
