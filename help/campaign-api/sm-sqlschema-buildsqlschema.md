# BuildSqlSchema

Génère le code d&#39;un schéma depuis la structure physique de la table identifiée en paramètre.

```text
XML schema = BuildSqlSchema ( String dataSource, String tableName )
```

## Paramètres

**dataSource** ID de la source de données

**tableName** Nom de la table

## Valeur(s) renvoyée(s)

**schéma** Schéma généré

## Fonctionnalités

**Schéma :** [xtk:sqlSchema](s-xtk-sqlschema.md)

**Statique :**

Oui
