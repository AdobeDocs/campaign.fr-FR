# getAttributeNS

Renvoie la valeur de l’attribut.

```text
getAttributeNS (namespaceURI, localName)
```

## Paramètres

**namespaceURI** URI de l’espace de noms d’attribut.

**localName** Nom de l’attribut.

## Valeur renvoyée

Valeur de texte d’attribut.
