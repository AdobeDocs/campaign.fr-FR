# DOMCharacterData (classe)

Nœud contenant uniquement du texte. Il peut s’agir d’un nœud de type texte ou d’un commentaire.

## Méthodes

| Méthode | Description |
| --- | --- |
| [données de sous-chaîne](m-domcharacterdata-substringdata.md) | Extrayez une partie du texte. |
| [appendData](m-domcharacterdata-appenddata.md) | Ajoutez une chaîne de caractères au texte. |
| [insertData](m-domcharacterdata-insertdata.md) | Insère une chaîne de caractères dans le texte à un emplacement spécifique. |
| [deleteData](m-domcharacterdata-deletedata.md) | Supprimez une partie du texte. |
| [replaceData](m-domcharacterdata-replacedata.md) | Remplacez une partie du texte. |

## Propriétés

| Propriété | Description |
| --- | --- |
| [données](p-domcharacterdata-data.md) | Valeur texte du nœud. |
| [longueur](p-domcharacterdata-length.md) | Nombre de caractères dans le nœud |
