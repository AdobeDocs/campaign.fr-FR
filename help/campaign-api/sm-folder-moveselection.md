# MoveSelection

Déplace la sélection dans un noeud de l&#39;arborescence de navigation

```text
MoveSelection ( String schemaId, String entityFolder, XML selectionList, String key )
```

## Paramètres

**schemaId** Identifiant du schéma de sélection

**entityFolder** Id du dossier de destination

**selectionList** Sélection à déplacer

**clé** clé du nœud

## Valeur(s) renvoyée(s)

Aucune.

Oui
