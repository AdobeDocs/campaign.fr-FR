# hasAttributeNS

Tester l’existence d’un attribut.

```text
hasAttributeNS (namespaceURI, localName)
```

## Paramètres

**namespaceURI** URI de l’espace de noms d’attribut.

**localName** Nom de l’attribut.

## Valeur renvoyée

true si l’attribut existe, sinon false.
