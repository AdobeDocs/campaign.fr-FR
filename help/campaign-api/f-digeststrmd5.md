# digestStrMd5

> Avertissement :
>
> Cette fonction ne doit pas être utilisée pour créer un hachage basé sur des informations personnelles.

Calcule la fonction de hachage MD5 pour une chaîne de caractères. La chaîne est automatiquement codée au format UTF-8 avant le calcul.

```text
digestStrMd5 (string)
```

## Paramètres

**string** Chaîne pour laquelle la fonction de hachage doit être calculée.

## Valeur renvoyée

Le hachage MD5 de la chaîne passée en paramètre.
