# GetCleanedValue

Récupère une version nettoyée d&#39;une valeur.

```text
String value = GetCleanedValue ( Number enumId, String alias )
```

## Paramètres

**enumId** ID de l’énumération

Valeur **alias** à remplacer

## Valeur(s) renvoyée(s)

**value** Valeur nettoyée (si non trouvée, retourne l&#39;alias)

**Schéma :** [xtk:enum](s-xtk-enum.md)

**Statique :**

Oui
