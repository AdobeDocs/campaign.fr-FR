# getRemoteAddr

Renvoie l’adresse IP du client ou du dernier proxy à avoir envoyé une requête.

```text
getRemoteAddr ()
```

## Paramètres

Aucune.

## Valeur renvoyée

Chaîne contenant l’adresse IP du client qui a envoyé la requête.

## Fonctionnalités

**Méthode de classe :** [HttpServletRequest](c-httpservletrequest.md)

**Disponible en :**

* JSSP
* WEBAPP
