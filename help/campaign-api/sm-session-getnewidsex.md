# GetNewIdsEx

Récupère une liste d&#39;identifiants uniques de la base de données en spécifiant un nom de séquence.

```text
String idList = GetNewIdsEx ( Number count, String sequence )
```

## Paramètres

**count** Nombre d&#39;identifiants que cette méthode doit renvoyer

**séquence** Nom de la séquence à incrémenter

## Valeur(s) renvoyée(s)

**idList** liste des identifiants séparés par des virgules
