# GetUsedLanguagesEnum

Crée une énumération avec les langues utilisées dans le rapport.

```text
XML enum = GetUsedLanguagesEnum ( String designLanguage, String defaultLanguage, XML additionalLanguages )
```

## Paramètres

**designLanguage** Langue de conception

**defaultLanguage** Langue par défaut

**additionalLanguages** Autres langues

## Valeur(s) renvoyée(s)

**enum**, énumération avec les langues utilisées
