# createProcessingInstruction

Crée une nouvelle instruction de traitement.

```text
createProcessingInstruction (target, data)
```

## Paramètres

**target** Instruction de traitement cible, par exemple &lt;?php ... ?>.

**data** Chaîne de caractères à insérer dans l&#39;instruction.

## Valeur renvoyée

[processinginstruction](c-domnode.md) créée.
