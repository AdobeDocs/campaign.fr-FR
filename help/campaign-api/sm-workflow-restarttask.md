# RedémarrerTâche

Force le redémarrage d’une ou plusieurs tâches terminées.

```text
RestartTask ( String workflowId, String activityName )
```

## Paramètres

**workflowId** Identifiant ou nom interne du workflow.

**activityName** Nom de la ou des activités à redémarrer

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [xtk:workflow](s-xtk-workflow.md)

**Statique :**

Oui
