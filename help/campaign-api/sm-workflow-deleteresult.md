# DeleteResult

Efface les resultats d’une ou plusieurs activités.

```text
DeleteResult ( String workflowId, String activityName )
```

## Paramètres

**workflowId** Identifiant ou nom interne du workflow.

**activityName** Nom de la ou des activités dont vous souhaitez effacer les résultats

## Valeur(s) renvoyée(s)

Aucune.

**Schéma :** [xtk:workflow](s-xtk-workflow.md)

**Statique :**

Oui
