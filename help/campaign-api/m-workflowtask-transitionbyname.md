# transitionByName

Renvoie les transitions correspondant au nom donné.

```text
transitionByName (name)
```

## Paramètres

**nom** Nom de la transition.

## Valeur renvoyée

La transition de ce nom passée en paramètre, sinon null si l&#39;activité n&#39;a pas de transition de ce nom.

## Fonctionnalités

**Méthode de classe :** [WorkflowTask](c-workflowtask.md)

* Workflow
