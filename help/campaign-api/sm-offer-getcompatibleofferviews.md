# GetCompatibleOfferViews

Retourne la liste des représentations compatibles avec cette offre.

```text
XML offerViews = GetCompatibleOfferViews ( Number offerId )
```

## Paramètres

**offerId** Identifiant de l&#39;offre

## Valeur(s) renvoyée(s)

**Représentations compatibles offerViews**

## Fonctionnalités

**Schéma :** [nms:offer](s-nms-offer.md)

**Statique :**

Oui
