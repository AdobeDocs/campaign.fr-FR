# sha256

Calcule la signature SHA-2 256 bits du contenu MemoryBuffer.

```text
sha256 ()
```

## Paramètres

Aucune.

## Valeur renvoyée

Une chaîne de caractères qui est la représentation hexadécimale de la signature SHA-2 256 bits.
