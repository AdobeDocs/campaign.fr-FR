# createTextNode

Crée un nœud de type texte.

```text
createTextNode (data)
```

## Paramètres

**data** Chaîne de caractères à insérer dans le nœud de texte.

## Valeur renvoyée

Nœud de type [DOMCharacterData](c-domcharacterdata.md) créé.
