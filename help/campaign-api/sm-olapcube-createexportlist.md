# CreateExportList

Crée la liste dans laquelle seront exportées les entités du panier.

```text
Number listId = CreateExportList ( String label, Number folderId )
```

## Paramètres

**libellé** Libellé de la liste

**folderId** ID du dossier dans lequel la liste sera créée (0 pour utiliser le dossier par défaut).

## Valeur(s) renvoyée(s)

**listId** ID de la liste nouvellement créée

**Statique :**

Oui
