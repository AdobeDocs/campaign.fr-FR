# Entité (Classe)

Représente une entité de la base de données pour un schéma donné.

Un tel objet ne peut pas être instancié directement. Vous devez utiliser les méthodes create(), get() ou load().

## Méthodes

| Méthode | Description |
| --- | --- |
| [enregistrer](m-entity-save.md) | Enregistre une entité dans la base de données. |
