# replaceData

Remplacez une partie du texte.

```text
replaceData (offset, count, arg)
```

## Paramètres

**décalage** Position du premier caractère à supprimer (0 pour le premier caractère).

**count** nombre de caractères à supprimer.

**arg** Chaîne de caractères à insérer.

## Valeur renvoyée

Aucune.
