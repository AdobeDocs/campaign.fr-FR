# Déployer

Déploiement des catégories vers un environnement.

```text
Deploy ( XML offerCategoryFilter, Number offerEnv )
```

## Paramètres

**offerCategoryFilter** Condition de filtrage définissant les catégories à copier

**offerEnv** Identifiant de l’environnement de destination

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [nms:offerCategory](s-nms-offercategory.md)

**Statique :**

Oui
