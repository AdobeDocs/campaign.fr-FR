# FileEdit

Ce contrôle permet de saisir un nom de fichier.

![Contrôle FileEdit](assets/fileedit.56228d2a.png)

## Propriétés

**backColor - chaîne** Couleur d&#39;arrière-plan (btnshasow, blanc).

**border - string** Modifie le style de bordure lors du contrôle (uni, double, inséré, départ, aucun).

**dlgType - string** Type de la fenêtre de sélection du fichier (save, opendir, savedir).

**filtres - chaîne** Liste de filtres

**font-size - integer** Modifie la taille de la police.

**libellé - chaîne** libellé associé.

**lastPath - string** Chemin d’accès de la fenêtre de sélection du fichier.

**loadContent - boolean** Charge le contenu d&#39;un fichier.

**nolabel - boolean** Masque le libellé associé.

**readOnly - boolean** Force le contrôle en lecture seule.

**obligatoire - booléen** Le champ est obligatoire.

**titre - chaîne** Titre de la fenêtre de sélection

**xpathCopyName - xpath** Chemin d’accès pour stocker le nom du fichier (avec son extension).

**xpathType - xpath** Type de fichier (texte ou XML)
