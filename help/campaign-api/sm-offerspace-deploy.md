# Déployer

Déploiement des emplacements vers un environnement.

```text
Deploy ( XML offerSpaceFilter, Number offerEnv )
```

## Paramètres

**offerSpaceFilter** Condition de filtrage définissant les emplacements à copier

**offerEnv** Identifiant de l’environnement de destination

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [nms:offerSpace](s-nms-offerspace.md)

**Statique :**

Oui
