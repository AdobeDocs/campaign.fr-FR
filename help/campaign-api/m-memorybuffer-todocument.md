# toDocument

Retourne un document XML à partir du contenu texte de ce buffer.

```text
toDocument ( [codePage ])
```

## Paramètres

**codePage** Entier codant la page de caractères utilisée. Par défaut MemoryBuffer.CODEPAGE\_UTF8.

## Valeur renvoyée

Un objet de type [DOMDocument](c-domdocument.md).
