# createElementNS

Crée un nouvel élément avec le nom et l&#39;espace de noms spécifiés.

```text
createElementNS (namespaceURI, qualifiedName)
```

## Paramètres

**namespaceURI** URI d’espace de noms.

**qualifiedName** Nom qualifié de l’élément à créer.

## Valeur renvoyée

[élément](c-domelement.md) créé.
