# SwitchValuesAndAliases

Convertir une valeur en alias et réciproquement.

```text
SwitchValuesAndAliases ( XML enums, String mode )
```

## Paramètres

**enums** Collection des énumérations à convertir.

**mode** Mode de conversion : doit être &#39;ValuesToAliases&#39; ou &#39;AliasesToValues&#39;.

## Valeur(s) renvoyée(s)

Aucune.
