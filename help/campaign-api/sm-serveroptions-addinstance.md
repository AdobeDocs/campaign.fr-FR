# AddInstance

> Avertissement : cette fonction est disponible pour un environnement On-Premise.

Déclare une nouvelle instance sur le serveur

```text
AddInstance ( String instanceName, String hosts, String lang )
```

## Paramètres

**instanceName** Nom de l’instance à créer

**hôtes** masques DNS associés à l’instance

**lang** Langue de l&#39;instance

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [xtk:serverOptions](s-xtk-serveroptions.md)

**Statique :**

Oui
