# setAttribute

Modifiez la valeur d’un attribut ou créez-en un.

```text
setAttribute (name, value)
```

## Paramètres

**name** Nom de l’attribut.

**value** Valeur de texte d’attribut.

## Valeur renvoyée

Aucune.
