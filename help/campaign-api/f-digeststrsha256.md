# digestStrSha256

Calcule le hachage SHA-256 d’une chaîne de caractères. La chaîne est automatiquement codée au format UTF-8 avant le calcul.

```text
digestStrSha256 (string)
```

## Paramètres

**string** Chaîne dans laquelle le hachage doit être calculé.

## Valeur renvoyée

Le hachage SHA-256 de la chaîne transmise en tant que paramètre.
