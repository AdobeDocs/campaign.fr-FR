# Fichier

Crée un nouvel objet associé à un fichier.

```text
File (filename)
```

## Paramètres

**filename** Nom du fichier à lire ou à créer.

## Valeur renvoyée

Aucune.

## Remarques

Exemple:

```javascript
var f = new File("/tmp/file.txt")
```
