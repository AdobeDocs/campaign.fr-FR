# setIdAttributeNS

Déclare l’attribut spécifié en tant qu’attribut de type ID.

```text
setIdAttributeNS (namespaceURI, localName)
```

## Paramètres

**namespaceURI** URI de l’espace de noms d’attribut.

**localName** Nom de l’attribut.

## Valeur renvoyée

Aucune.
