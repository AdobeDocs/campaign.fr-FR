# getUUID

Génération d’un identifiant unique (Identifiant universel unique).

```text
getUUID ()
```

## Paramètres

Aucune.

## Valeur renvoyée

Une chaîne de caractères contenant un identifiant unique de type &#39;550E8400-E29B-41D4-A716-446655440000&#39;.
