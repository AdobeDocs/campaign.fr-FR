# RecipientSubscribe

Abonner/désinscrire les destinataires sélectionnés à une liste de services d&#39;information

```text
XML confirmationIds = RecipientSubscribe ( XML recipientList, XML serviceList, Boolean subscribe, XML sendConfirmation )
```

## Paramètres

**liste des destinataires** Liste des destinataires

**serviceList** Liste des services

**s&#39;abonner** Abonner/désabonner les destinataires

**sendConfirmation** Envoyez un message de confirmation

## Valeur(s) renvoyée(s)

**confirmationIds** Liste des ID de confirmation

## Fonctionnalités

**Schéma :** [nms:subscription](s-nms-subscription.md)

**Statique :**

Oui
