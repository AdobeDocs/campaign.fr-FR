# GetActiveApplicationMenus

Retourne un document contenant les menus des applications actives sur le login courant

```text
XML doc = GetActiveApplicationMenus ()
```

## Paramètres

Aucune.

## Valeur(s) renvoyée(s)

Résultat **doc**

**Schéma :** [xtk:session](s-xtk-session.md)

**Statique :**

Oui
