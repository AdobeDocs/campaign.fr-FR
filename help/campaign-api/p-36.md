# Page de directives

Inclut une bibliothèque de fonctions ou de chaînes.

## Syntaxe

&lt;%@ page import=« lib1, ... » %> &lt;%@ page stringGroup=« groupName » %>

## Description

L’importation d’une bibliothèque de chaînes expose un objet JavaScript global dont le nom commence par sg\_ suivi du nom de la bibliothèque dont les caractères spéciaux ont été remplacés par « \_ ». Par exemple, l’inclusion de nms:campaign crée la variable sg\_nms\_campaign.

## Exemple

```xml
      <%@ page import="xtk:shared/nl.js,nms:campaign.js" %>
<%@ page stringGroup="nms:campaign" %>
...
<%= sg_nms_campaign.stateLabel() %>
...
```
