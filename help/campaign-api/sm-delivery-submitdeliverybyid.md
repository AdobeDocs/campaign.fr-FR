# SubmitDeliveryById

Création et soumission d&#39;une diffusion depuis un modèle (renseigné par son identifiant interne).

```text
Number deliveryId = SubmitDeliveryById ( Number scenarioId, XML content )
```

## Paramètres

Identifiant du modèle **scenarioId**

Contenu XML **content** à ajouter au modèle

## Valeur(s) renvoyée(s)

Contenu XML **deliveryId** à ajouter au modèle
