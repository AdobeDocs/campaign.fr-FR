# addHeader

Ajoute un en-tête HTTP supplémentaire à la réponse.

```text
addHeader (nom, valeur)
```

## Paramètres

**nom** Nom de l’en-tête à ajouter.

**valeur** de l’en-tête ajouté.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Méthode de classe :** [HttpServletResponse](c-httpservletresponse.md)

**Disponible en :**

* JSSP
* WEBAPP
