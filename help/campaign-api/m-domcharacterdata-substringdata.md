# substringData

Extrayez une partie du texte.

```text
substringData (offset, count)
```

## Paramètres

**décalage** Position du premier caractère (0 pour le premier caractère).

**count** Nombre de caractères à extraire.

## Valeur renvoyée

Chaîne de caractères extraite.
