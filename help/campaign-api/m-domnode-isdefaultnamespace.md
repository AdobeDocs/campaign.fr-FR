# isDefaultNamespace

Teste si l’espace de noms donné est l’espace par défaut.

```text
isDefaultNamespace (namespaceURI)
```

## Paramètres

**namespaceURI** URI d’espace de noms.

## Valeur renvoyée

true si namespaceURI est l’espace de noms par défaut, sinon false.
