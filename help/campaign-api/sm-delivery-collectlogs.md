# CollectLogs

Crée une table avec l&#39;ensemble des messages de log de diffusion d&#39;une liste de diffusions

```text
CollectLogs ( Number id, XML deliveries, String logTable )
```

## Paramètres

Identifiant unique de la priorisation **id**

**diffusions** liste des diffusions à prendre en compte

Table **logTable** à créer pour contenir tous les messages du journal

## Valeur(s) renvoyée(s)

Aucune.

## Fonctionnalités

**Schéma :** [nms:delivery](s-nms-delivery.md)

**Statique :**

Oui
