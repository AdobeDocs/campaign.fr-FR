# sendError

Renvoie une réponse d’erreur à l’aide du code d’erreur transmis en tant que paramètre.

```text
sendError (errorCode)
```

## Paramètres

**errorCode** Code d’erreur HTTP.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Méthode de classe :** [HttpServletResponse](c-httpservletresponse.md)

**Disponible en :**

* JSSP
* WEBAPP
