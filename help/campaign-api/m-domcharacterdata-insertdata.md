# insertData

Insère une chaîne de caractères dans le texte à un emplacement spécifique.

```text
insertData (offset, arg)
```

## Paramètres

**offset** Position d&#39;insertion (0 pour le premier caractère).

**arg** Chaîne de caractères à insérer.

## Valeur renvoyée

Aucune.
