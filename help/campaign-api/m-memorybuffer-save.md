# enregistrer

> Avertissement :
>
> L’accès via les API de fichiers est limité aux dossiers **var**, **sftp** et temporaires d’Adobe Campaign.

Enregistre le contenu du buffer dans un fichier.

```text
save (filename)
```

## Paramètres

**filename** Nom du fichier à enregistrer.

## Valeur renvoyée

Aucune.

## Fonctionnalités

**Méthode de classe :** [MemoryBuffer](c-memorybuffer.md)

**Disponible en :**

* Gestion de contenu
* Propriétés de la diffusion
* Message de diffusion
* Règle de typologie
* Import
* JSSP
* Méthode SOAP
* WebApp
* Workflow
