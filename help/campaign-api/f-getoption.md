# getOption

Renvoie la valeur d’une option dans le tableau des options.

```text
getOption (name [, useCache ])
```

## Paramètres

**nom** Nom de l’option.

**useCache** Utilisez le cache de valeur d&#39;option (par défaut, il n&#39;est pas utilisé).

## Valeur renvoyée

Valeur de l’option si l’option existe, sinon non définie. Le type de la valeur dépend du type de l’option.
