# toString

Renvoie le contenu de [MemoryBuffer](c-memorybuffer.md) sous la forme d&#39;une chaîne de caractères.

```text
toString ( [codePage ])
```

## Paramètres

**codePage** Nombre entier qui code la page de caractères utilisée. Par défaut, MemoryBuffer.CODEPAGE\_UTF8.

## Valeur renvoyée

Contenu d’un tampon sous la forme d’une chaîne de caractères.
