# removeAttributeNS

Supprimez un attribut.

```text
removeAttributeNS (namespaceURI, localName)
```

## Paramètres

**namespaceURI** URI de l’espace de noms d’attribut.

**localName** Nom de l’attribut.

## Valeur renvoyée

Aucune.

## Remarques

La méthode n’a aucun effet si l’élément ne comporte aucun attribut de ce nom.
