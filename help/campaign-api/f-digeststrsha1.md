# digestStrSha1

> Avertissement :
>
> Cette fonction ne doit pas être utilisée pour créer un hachage basé sur des informations personnelles.

Calcule le hachage SHA-1 d’une chaîne de caractères. La chaîne est automatiquement codée au format UTF-8 avant le calcul.

```text
digestStrSha1 (string)
```

## Paramètres

**string** Chaîne dans laquelle le hachage doit être calculé.

## Valeur renvoyée

Le hachage SHA-1 de la chaîne transmise en tant que paramètre.
