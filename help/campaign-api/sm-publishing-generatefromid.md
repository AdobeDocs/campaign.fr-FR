# GenerateFromId

Génère et publie à partir d&#39;un répertoire un contenu depuis son identifiant

```text
String outputFiles = GenerateFromId ( String id, String publishingDir )
```

## Paramètres

Identifiant de contenu **id**

Dossier de publication **publishingDir**

## Valeur(s) renvoyée(s)

**outputFiles** Liste des fichiers générés
