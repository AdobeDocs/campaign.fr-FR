# serverURL

Retourne l’URL d’accès au serveur.

```text
serverURL
```

## Remarques

Peut être vide si ni HTTPS ni proxy ne sont utilisés

## Fonctionnalités

**Propriété de la classe :** [HttpServletRequest](c-httpservletrequest.md)

**Lecture seule :**

Oui

**Disponible en :**

* JSSP
* WEBAPP
