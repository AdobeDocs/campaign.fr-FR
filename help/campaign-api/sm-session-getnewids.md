# GetNewIds

Récupère une liste d&#39;identifiant de clés internes de la base de données.

```text
String idList = GetNewIds ( Number count )
```

## Paramètres

**count** Nombre d&#39;identifiants que cette méthode doit renvoyer

## Valeur(s) renvoyée(s)

**idList** liste des identifiants séparés par des virgules
